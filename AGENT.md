# Repository Instructions

Before performing any task in this repository:

1. Read the root RULE.md completely.
2. Follow all engineering, architecture, code quality and Git rules defined there.
3. Inspect existing implementation before creating or modifying files.
4. Never assume that an existing feature is fully implemented.
5. Do not make unrelated changes.
6. Work in small, testable implementation chunks.
7. Protect all existing uncommitted changes.
8. Report actual test results and implementation status.

RULE.md is the primary engineering policy for this repository.

Reuse existing code, explain non-obvious boundaries with short comments, keep verification honest and record completed/pending features in docs/FEATURE_ROADMAP.md.
